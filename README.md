# Manhunt Mod

A Fabric mod for Minecraft 26.2 that adds Speedrunner vs Hunter roles.

Commands:
- `/manhunt set <player> <role>` - assign role
- `/manhunt remove <player>` - remove role
- `/manhunt list` - list all players with roles
- `/manhunt random` - randomly assign roles (1 speedrunner, rest hunters)
- `/manhunt clear` - clear all roles

Build with `.\gradlew build`
